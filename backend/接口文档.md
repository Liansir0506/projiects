# 小麦病虫害智能诊断系统 - 后端接口对接文档（5号 → 6号）

> 版本：v2.0
> 更新日期：2026-08-16
> 服务地址：http://127.0.0.1:8000
> 在线文档：http://127.0.0.1:8000/docs


## 一、接口一览

| 方法 | 路由 | 功能 | 请求体 | 响应 data |
| :---: | :--- | :--- | :--- | :--- |
| GET | `/api/v1/health` | 健康检查 | 无 | `{"status": "running", "service": "...", "version": "..."}` |
| GET | `/api/v1/classes` | 获取15类病害列表 | 无 | `{"classes": [{"class_id": 1, "class_name": "小麦蚜虫", "class_name_en": "Aphid"}, ...]}` |
| POST | `/api/v1/diagnoses` | 智能诊断（上传图片识别病害） | `multipart/form-data`：`image`(文件)、`region`(字符串)、`growth_stage`(字符串)、`field`(字符串，可选) | `{"diagnosis_id": "D202608150001", "created_at": "...", "region": "西安", "growth_stage": "抽穗期", "field": "试验田1号", "image_quality": {"status": "success", "message": "..."}, "predictions": [{"class_id": 15, "class_name": "小麦条锈病", "display_name": "小麦条锈病", "confidence": 0.85}, ...], "reliable": true, "threshold": 0.65, "knowledge": {"introduction": "...", "symptoms": ["..."], "prevention": ["..."]}, "weather_risk": {"level": "low", "summary": "...", "daily": []}, "record_saved": true}` |
| GET | `/api/v1/diagnoses` | 获取历史诊断记录列表 | 无 | `{"records": [{"diagnosis_id": 1, "created_at": "...", "region": "西安", "field": "试验田1号", "growth_stage": "抽穗期", "predicted_class": "小麦条锈病", "confidence": 0.85, "reliable": true, "risk_level": "low"}, ...]}` |
| GET | `/api/v1/diagnoses/{id}` | 获取单条诊断详情 | 无（URL 参数 `id`） | 同历史记录中的单条结构 |
| GET | `/api/v1/statistics` | 获取数据统计 | 无 | `{"total_diagnoses": 15, "by_class": {"小麦条锈病": 8}, "by_reliable": {"reliable": 13, "unreliable": 2}, "by_risk_level": {"low": 10, "medium": 3, "high": 2}, "recent_high_risk": [], "daily_trend": []}` |


## 二、统一规范说明

### 2.1 全局返回格式
所有接口统一返回以下格式：

```json
{
    "code": 0,          // 0=成功，非0=业务异常
    "msg": "success",   // 提示信息
    "data": {}          // 实际业务数据
}
