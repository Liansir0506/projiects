## 一、项目概述

本模块为系统后端核心枢纽，提供 RESTful API，串联模型推理（4号）、知识库（7号）、天气与数据库（8号）三大能力，供前端（6号）调用。

当前版本内置 Mock 模拟层，可在无真实模块时独立运行和测试。

## 三、统一接口契约

### 3.1 全局规范

| 规范项 | 约定 |
| :--- | :--- |
| 接口路径前缀 | `/api/v1/` |
| HTTP 状态码 | 永远返回 200 |
| 业务状态 | 通过返回体 `code` 字段区分（0=成功，非0=异常） |
| 统一返回格式 | `{"code": 0, "msg": "success", "data": {}}` |
| 图片格式 | JPG / JPEG / PNG |
| 图片大小 | ≤ 10MB |
