# 小麦病虫害智能诊断系统 - 后端模块对接说明

## 1. 模块概述
本模块为系统后端核心枢纽，提供 RESTful API，串联模型推理（4号）、知识库（7号）、天气与数据库（8号）三大能力，供前端（6号）调用。当前版本内置 Mock 模拟层，可在无真实模块时独立运行和测试。

## 3. 快速运行（保姆级步骤）

### 3.1 环境准备
- Python 3.8+ 已安装
- 建议使用虚拟环境（如 venv 或 conda）

```bash
# 创建并激活虚拟环境（可选）
python -m venv venv
source venv/bin/activate   # Linux/Mac
# 或 venv\Scripts\activate  # Windows

# 安装依赖
cd backend
pip install -r requirements.txt
